# 单文件提词器（iPhone Safari 专用）

为抖音口播设计的单文件网页提词器：一个 `index.html` 包含全部 HTML/CSS/JS，
**零外部依赖、零构建、零 CDN**。已部署公网（GitHub Pages），可离线使用。

## 文件说明

- `index.html` — 提词器全部代码，任何静态服务器都能跑
- `maker.html` — 提词视频生成器（在电脑浏览器打开，把稿子渲染成 MP4）
- `sw.js` — Service Worker（HTTP/HTTPS 环境下自动注册，提供断网可用的离线缓存）
- `icon.png` — 180x180 主屏幕图标（必须和 index.html 放同一目录）
- `README.md` — 本说明

## 〇、在线版（推荐，不依赖电脑）

1. iPhone Safari 打开 **https://cch778.github.io/teleprompter/**
2. 首次打开后 Service Worker 会把页面缓存到手机；Safari 分享 →「添加到主屏幕」
3. 之后从主屏幕图标打开；**即使手机断网 / 没有信号也能正常用**（脚本数据本就存在手机里）

## 一、备用：在电脑上起服务（局域网，无需互联网）

1. iPhone 和电脑连接**同一个 Wi-Fi**（手机热点连电脑也可以）
2. 在本目录打开终端（Git Bash / PowerShell 均可）运行：

   ```
   python -m http.server 8000
   ```

3. 查电脑局域网 IP：运行 `ipconfig`，找「IPv4 地址」，例如 `192.168.1.5`
4. 首次启动若弹出 Windows 防火墙提示，选择「允许访问」
5. iPhone Safari 访问 `http://192.168.1.5:8000`

> 在线版和局域网版是两个不同的"网站"，各自存各自的脚本，数据不互通；固定用其中一个即可。

## 二、iPhone 上使用（添加到主屏幕）

1. **强烈建议添加到主屏幕**：Safari 底部分享按钮 →「添加到主屏幕」→ 名字默认「提词器」
2. 从主屏幕图标打开，即为全屏独立模式（无地址栏、无工具栏），录屏更干净

## 三、基本操作

| 界面 | 操作 |
| --- | --- |
| 首页 | 「＋」新建脚本；点卡片进入编辑；卡片上的「复制」「删除」（删除有确认） |
| 编辑 | 标题 + 正文，输入停顿 500ms 自动保存；可直接粘贴长文本；「开始提词」进入播放 |
| 播放 | 点屏幕文字：暂停 / 继续；底部控制条：播放暂停、速度 ±10（10~200）、字号 ±8（16~120）、3-2-1 倒计时开关、镜像开关（配提词器硬件）、小窗开关、倒退一屏、返回编辑 |
| 播放 | 双指捏合：两指张合随时放大 / 缩小字号（16~120），松手自动保存 |
| 播放 | 控制条 4 秒无操作自动淡出，点屏幕任意处唤出；顶部细进度条；滚完显示「已完成」 |

播放页会自动保持屏幕常亮（iOS 16.4+ 走系统 Wake Lock，更早的系统走静音循环视频兜底）。

## 四、画中画小窗（Safari 标签页内）与它的限制

在 **Safari 标签页**（不是桌面图标）打开本页，进播放页点「小窗」，文字以系统画中画小窗显示，可拖动；速度/暂停回本页调整实时同步；双指捏合可调字号。

> ⚠️ **iOS 的硬限制（实测）**：
> - **桌面图标（主屏幕独立）模式完全不支持小窗**，点击会提示改用 Safari 标签页
> - Safari 里切到相机等 app 后，系统可能**冻结网页**，实时小窗会静止或黑屏
>
> 想在**录像时**用悬浮提词，用下面的预生成视频方案，那个永不冻结。

## 五、生成提词视频（录像悬浮提词 · 推荐）

把稿子提前渲染成 MP4，用系统播放器的画中画——**系统级驱动永不冻结、自带进度条可拖到任意段落、可暂停**：

1. **电脑**浏览器（新版 Chrome / Edge）打开 **https://cch778.github.io/teleprompter/maker.html**
2. 粘贴口播稿，调速度 / 字号 / 横竖向 → 「开始生成」
   （生成耗时 ≈ 视频时长，期间保持页面在前台；完成后自动下载 MP4）
3. 把 MP4 发到 iPhone（微信 / QQ / AirDrop 均可）→ **保存到相册**
4. 相册里全屏播放该视频 → 点播放器**画中画图标** → 视频缩小成悬浮小窗
5. 切到**相机**开始录 → 小窗悬浮在相机上，拖位置 / 拖进度 / 暂停都随你

## 六、数据与隐私

- 脚本存在手机本地 localStorage（键名 `teleprompter_scripts`），速度 / 字号等偏好存 `teleprompter_prefs`，**不上传任何数据**
- 页面会请求 Safari「持久化存储」以降低 7 天未使用被清数据的风险；重要脚本建议自己在备忘录留一份底稿
- 清除 Safari 网站数据会删掉全部脚本，操作前注意备份
